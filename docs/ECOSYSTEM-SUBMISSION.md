# CrewAI ecosystem research (unpublished)

CrewAI public documentation exposes an event bus, native listener system, tool hooks and Crew/Flow templates. Their Enterprise Marketplace form targets **submitted Crew or Flow templates**; it is not evidence of an official third-party SDK listing process. Do not submit this SDK there as if it were a Crew template. Evaluate official integration directory/community channels after native and Core E2Es pass, and avoid any “verified partner” claim.
